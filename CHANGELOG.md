# История версий

## После v1.0.0

Дата заключения союза и дата развода сохраняются отдельно. Персональная страница, публикации HTML и PDF, GEDCOM и MCP различают оба события. В старых записях сохраняется исходная дата союза.

## v1.0.0

Первая публичная версия Family Tree Studio. Включает офлайн-редактор, импорт и экспорт JSON и GEDCOM, публикацию HTML/PDF, MCP-коннектор и локального помощника. Для первого запуска подготовлено вымышленное дерево из 19 карточек.
