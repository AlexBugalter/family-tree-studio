# Помощник семейного дерева

Требуется Node.js 22 или новее. Коннектор работает на встроенных модулях Node.js.

## Локальный чат

1. Запустите локальный API в LM Studio или Unsloth и загрузите модель с поддержкой вызова инструментов. Коннектор проверяет порт 1234 для LM Studio и 8888 и 8889 для Unsloth. Если приложение показывает другой адрес, задайте его через переменную окружения с суффиксом `/v1`.
2. Откройте `Start-Family-Assistant.cmd`. В окне появятся адрес чата и токен. Перейдите по адресу, вставьте токен и нажмите «Проверить подключение».
3. Выберите сервер и модель. Спросите, например, «Кто родители человека с таким-то ФИО?» или «Добавь в биографию этой карточки следующий текст». Для записи проверьте показанные изменения и нажмите «Применить правку».
4. Нажмите «Скачать дерево JSON» и загрузите файл кнопкой «Загрузить» в редакторе. Редактор после загрузки держит собственную копию в браузере. Сохранённые в редакторе правки можно передать коннектору, указав новый экспорт в `FAMILY_TREE_FILE` и перезапустив коннектор.

В PowerShell для запуска в режиме чтения используйте `node mcp/server.cjs --http`. Перед запуском можно задать переменные окружения:

| Переменная | Назначение |
| --- | --- |
| `FAMILY_TREE_FILE` | Путь к рабочему JSON редактора. По умолчанию `data/tree_mcp.json`. |
| `FAMILY_TREE_SEED` | Стартовый экспорт, используемый до первой записи. По умолчанию для стандартного рабочего файла используется вымышленное дерево из `demo/tree.json`. При своём `FAMILY_TREE_FILE` задайте эту переменную, если рабочий файл ещё отсутствует. |
| `FAMILY_TREE_WRITE` | Значение `1` включает запись. CMD-скрипт включает её при запуске чата. |
| `FAMILY_MCP_PORT` | Порт чата и HTTP API, по умолчанию 8765. |
| `FAMILY_MCP_TOKEN` | Токен HTTP API от 24 символов. Если переменная отсутствует, коннектор выдаёт временный токен в консоли. |
| `FAMILY_LMSTUDIO_URL`, `FAMILY_UNSLOTH_URL` | Локальные базовые URL OpenAI-совместимого API. |
| `FAMILY_LMSTUDIO_KEY`, `FAMILY_UNSLOTH_KEY` | Токены провайдеров, если сервер модели требует аутентификацию. |

Если сервер доступен, но список моделей пуст, загрузите модель в приложении и повторите проверку. Доступность API и наличие модели определяются через `GET /models`. Ответы и вызовы инструментов идут через `POST /chat/completions`. Поддержка инструментов зависит от выбранной модели и её шаблона. [LM Studio Tool Use](https://lmstudio.ai/docs/developer/openai-compat/tools) · [Unsloth Tool Calling](https://unsloth.ai/docs/basics/tool-calling-guide-for-local-llms)

## MCP для агентов

Для LM Studio добавьте запись в `mcp.json` через «Program → Install → Edit mcp.json». Для других локальных MCP-клиентов используйте аналогичную настройку stdio. [Документация LM Studio](https://lmstudio.ai/docs/app/mcp)

```json
{
  "mcpServers": {
    "family-tree": {
      "command": "node",
      "args": ["C:/projects/family-tree-studio/mcp/server.cjs"]
    }
  }
}
```

Для записи из этого MCP-клиента добавьте в конфигурацию сервера `"env": {"FAMILY_TREE_WRITE": "1"}`. Оставьте режим чтения для агентов, которым нужна только справка.

Для агента с доступом к тому же компьютеру есть Streamable HTTP в режиме одиночных JSON-ответов на `http://127.0.0.1:8765/mcp`. Передайте `Authorization: Bearer <токен>`. Обычные API-клиенты могут получить схему через `GET /api/tools` и вызвать инструмент через `POST /api/tool` с телом `{"name":"family_tree_search","arguments":{"query":"Фамилия"}}`. Те же HTTP-заголовки требуются для `GET /api/models`, `POST /api/chat` и `GET /api/tree`. Сервис слушает только loopback. Агент на другом компьютере не сможет подключиться напрямую. Агент с облачной моделью может передавать ей возвращённые сведения дерева, если его подключить как MCP-клиента. [Спецификация транспорта MCP](https://modelcontextprotocol.io/specification/2025-11-25/basic/transports)

Скиллы находятся в [skills](../skills). Для среды, которая читает `SKILL.md`, добавьте соответствующие каталоги в её папку скиллов. MCP-клиенты с поддержкой prompts также могут получить эти инструкции через `prompts/list` и `prompts/get`.

## Данные и откат

Запись идёт в рабочую копию. Резервная копия предыдущего состояния сохраняется рядом с ней в `mcp-backups/`. Для отката остановите работающие экземпляры коннектора и укажите нужную резервную копию как источник для нового рабочего файла, либо откройте её в редакторе.

При одновременной записи с другой сессией устаревший предпросмотр отклоняется. Если процесс принудительно завершился во время записи и оставил `.lock`, проверьте, что экземпляры коннектора остановлены, прежде чем удалять именно этот файл блокировки.

Структурированные календарные даты и раздельные поля фамилии, имени и отчества редактируются в основном редакторе. Инструменты записи работают с профилями, родителями и союзами. Файлы фото и видео остаются в каталоге `media/`.
